# Sigma widget — Capacity Planning Agent

Installs the agent as a tab/panel **inside Zoho Projects** via Zoho Sigma.

## Contents
- `plugin-manifest.json` — Sigma/ZET manifest (service `PROJECTS`, widget location, connector scopes).
- `app/widget.html` · `app/widget.js` · `app/styles.css` — the widget UI (same flow as the Catalyst web app).
- `app/js/zet-context.js` — resolves the current portal via the ZET SDK.
- `app/lib/` — synced copy of `/core` (generated by `scripts/sync-core.mjs`).
- `assets/icon.png` — widget logo.

## Pack & publish (no git-native deploy exists for Sigma)
```bash
npm install -g zoho-extension-toolkit
node ../scripts/sync-core.mjs      # ensure app/lib is current
zet validate
zet pack                           # → sigma/dist/*.zip
```
Then upload the ZIP in the Zoho Sigma / Marketplace developer console and
install it into your portal. CI (`.github/workflows/package-sigma.yml`) does
the pack for you and attaches the ZIP as a downloadable build artifact.

## Backend
Set `window.CAPACITY_API` to your deployed Catalyst function URL so the widget's
"Set it up" step can call `/apply`. Without it, the widget stays in dry-run.

> Manifest note: Sigma's exact widget `location` keys and manifest schema evolve
> across versions of the platform. If `zet validate` flags the location, adjust
> it to the current Zoho Projects widget location from the Sigma docs — the app
> code itself is independent of that key.
